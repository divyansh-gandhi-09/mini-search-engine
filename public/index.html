Help & Technical Overview

Search Engine Overview

This mini search engine allows you to store, organize, and search documents efficiently using modern information retrieval techniques.

Core Features

  • TF-IDF Ranking: Each document is vectorized using Term Frequency–Inverse Document Frequency, enabling relevance scoring based on query terms.
  • Autocomplete: As you type, the system suggests possible query completions using prefix-based search structures for fast lookup.
  • Spelling Correction (BK-Tree): Typo-tolerant correction is implemented via a Burkhard-Keller Tree, which finds the closest word matches by edit distance.
  • Folder Organization: Documents can be grouped into folders for more efficient searching and management.
  • Index Rebuild: You can refresh or rebuild the index at any time to incorporate new or modified documents.
  • Metadata Tracking: The system tracks document IDs, names, and folders for quick retrieval and management operations.

Usage Instructions

  • Search: Enter a term or phrase and press Search to view ranked results. use 'and' / 'or' between terms to get boolean results
  • Show All: Displays all indexed documents.
  • Upload: Add new documents or text content manually.
  • Edit: Modify existing document content.
  • Delete: Permanently remove a document from the index.
  • Update/Rebuild Index: Refresh the TF-IDF and BK-Tree structures when data changes significantly.
